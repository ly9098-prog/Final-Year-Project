# GitHub 开源项目参考清单：STM32 手冲咖啡毕设

> **课题：** 基于 STM32 的手冲咖啡多参数 PID 闭环控制与萃取管理系统设计与实现  
> **整理日期：** 2026 年 10 月 9 日  
> **用途：** 为硬件方案、固件架构、称重与萃取流程提供技术参考；不作为论文的学术文献替代品，也不作为可直接提交的完整毕设工程。

---

## 1. 当前课题与开源项目的对应关系

当前课题要求以 STM32 为主控，结合 WiFi、微信小程序、温度/流量/重量采集、PID 控制、配方管理、过程记录与复刻，完成一个物联网手冲咖啡系统。

截至本清单整理日，未检索到一个同时完整覆盖下列全部条件、可直接移植并满足本课题要求的开源项目：

- STM32 主控；
- 手冲咖啡注水机构；
- 温度、流量、重量三类反馈；
- 流量/重量闭环；
- WiFi、云端与微信小程序；
- 萃取曲线记录和复刻。

因此，建议采用“**整机流程参考 + STM32 控制参考 + 称重模块参考 + 自主集成实现**”的路线，而不是直接 Fork 某个仓库后改名使用。

## 2. 优先参考项目

### 2.1 TipsyBrew Pour Over Robot —— 手冲整机与机械/流程参考

- **仓库：** [mpboddie/TipsyBrewPourOver](https://github.com/mpboddie/TipsyBrewPourOver)
- **平台：** ESP32 / PlatformIO
- **许可证：** MIT
- **相关度：** 很高
- **推荐用途：** 手冲注水机构、泵与软管结构、称重平台、设备状态机、OLED/按键界面、温度/称重/电机任务划分。

仓库中含有 ESP32 工程、HX711 称重示例、泵测试、原理图、3D 打印结构文件，以及与温度、称重、电机、显示、WiFi 相关的任务文件。其“由简单流程开始、再逐步增加功能”的工程思路适合本课题的最低合格版本。

**可借鉴内容：**

- `tasks/weights.h`：称重采样与处理思路；
- `tasks/kettleTemp.h`：温度采集与显示组织方式；
- `tasks/motors.h`：泵/电机执行器组织方式；
- `states.h`：冲煮流程状态机；
- `schematics/`、`3dPrints/`：水路、泵、称重及外观结构的思路。

**不应直接照搬的部分：**

- ESP32 底层驱动、WiFi 实现和 PlatformIO 工程配置；
- 机械结构与 3D 模型，除非遵守 MIT 许可证并明确记录来源；
- 不应把该项目的完整设计、图片、代码或文字描述包装成本人原创成果。

### 2.2 Intelligent Pour-Over Coffee Machine —— 手冲系统架构与配方流程参考

- **仓库：** [PhiloCoffee/intelligent-pour-over-coffee-machine](https://github.com/PhiloCoffee/intelligent-pour-over-coffee-machine)
- **平台：** Raspberry Pi 5B / Python
- **许可证：** MIT
- **相关度：** 很高
- **推荐用途：** 系统分层、冲煮有限状态机、配方组织、传感器与执行器接口边界、整机测试思路。

该项目为高校课程设计性质的智能手冲咖啡机，包含主控程序、有限状态机、冲煮配置、重量采样、泵、电机、显示、通信等模块。它不适合直接移植到 STM32，但可作为“从配方到执行流程”的架构参考。

**可借鉴内容：**

- `fsm.py`：冲煮流程状态机；
- `coffee.py`：不同烘焙度或冲煮方案的参数组织；
- `hardware/sensor.py`、`hardware/pump.py`、`hardware/motor.py`：传感器和执行器分层；
- `config.py`：集中管理目标参数和硬件配置的方式。

**不应直接照搬的部分：**

- Python/Raspberry Pi GPIO 驱动；
- 项目报告中的实验结论、图表、照片或数据；
- 将其中的“AI/ChatGPT 通信”直接写为本课题已实现的功能。

### 2.3 SmartCoffeeMachine —— STM32 PID、状态机与保护策略参考

- **仓库：** [a174844/SmartCoffeeMachine](https://github.com/a174844/SmartCoffeeMachine)
- **平台：** STM32F103C8T6 / C
- **许可证：** MIT
- **相关度：** 高
- **推荐用途：** STM32 固件目录结构、PID、滤波、执行器 PWM、故障锁存、冲煮状态机。

该项目面向意式咖啡机而非手冲咖啡，主要包含水温、压力与奶泡温度的控制。但其固件分层很适合借鉴到本课题：将“压力控制”替换为“流量控制”，将“冲煮流程”替换为“闷蒸—分段注水—结束”的手冲流程。

**优先阅读的文件：**

```text
common/pid.c
common/filters.c
firmware/sensors.c
firmware/actuators.c
firmware/brew.c
firmware/faults.c
firmware/protection.c
```

**可迁移的设计思想：**

- 传感器采样、滤波和单位换算分层；
- PID 控制与执行器 PWM 分层；
- 状态机集中管理工作流程；
- 传感器故障、超温、异常状态下的停机与报警；
- 参数校准与运行时保护独立实现。

**本课题的自主改造重点：**

```text
温度采样 → 温度 PID → PTC 加热模块
流量脉冲 → 流量估算/控制 → 水泵或阀门
HX711 称重 → 粉水比/目标液重判断 → 注水停止
手冲状态机 → 预热 / 闷蒸 / 分段注水 / 完成
安全策略 → 超温 / 缺水 / 无流量 / 称重异常 / 通信异常
```

### 2.4 Coffee Scale Timer —— HX711 称重与咖啡计时参考

- **仓库：** [drewzilla37/coffee-scale-timer](https://github.com/drewzilla37/coffee-scale-timer)
- **平台：** Arduino / C++
- **许可证：** MIT
- **相关度：** 中高
- **推荐用途：** HX711 标定、去皮、称重显示、计时逻辑、按键交互、OLED 信息布局。

该项目规模小、功能集中，适合作为“粉重/液重采集 + 计时”的最低实现参考。

**可借鉴内容：**

- 开机去皮与手动去皮流程；
- 不同重量精度的显示策略；
- 开始、暂停、复位的状态切换；
- HX711 采样结果与 OLED 显示的组织方式。

**本课题需要自行新增：**

- 粉水比计算；
- 目标液重自动终止；
- WiFi 上传；
- 配方、历史记录和微信小程序联动。

## 5. 开源使用与论文写作注意事项

1. **GitHub 项目不是学术论文。** 其内容可作为工程技术资料、方案来源或开源组件来源，但不能代替开题报告和毕业论文所需的学术文献。
2. **许可证优先。** 使用任何代码、原理图、模型或图片前，先核对该仓库及具体文件的许可证；许可证不明确时，不复制实现。
3. **MIT 不等于无需说明。** 若复用 MIT 项目中的代码或资源，应保留原版权和许可声明，并在工程/附册中注明来源。
4. **GPL 代码不宜直接混入。** 为减少许可证与提交边界问题，GPL 项目优先只参考设计思路并独立实现。
5. **论文应如实描述本人的新增工作。** 不得将开源项目的实验结果、照片、结构设计、图表、代码或文字描述成自己的原创成果。
6. **不要使用开源内容伪造实验。** 温控精度、流量误差、称重误差、网络延迟和曲线复刻效果必须以本人的实际测试记录为准。
